# Ecosonda EchoLogger ECT D032S

![Portada ECT D032S](/img/sensores/echologger-d032.png)

# Especificaciones Técnicas

| Parámetro | Valor |
|---|---|
| Frecuencia acústica | 30 kHz / 200 kHz (dual) |
| Ancho de haz | 26° / 5° cónico (-3dB, modo eco) |
| Ancho de pulso de transmisión | 100 µs ~ 1,000 µs |
| Potencia de transmisión | Máx. 30 W, ajustable |
| Control TVG | Hasta 60 dB |
| Control de ganancia | -30 dB a +30 dB |
| Rango de distancia de operación | 1.5 ~ 200 m (30 kHz) / 0.5 ~ 200 m (200 kHz) |
| Tasa de repetición (ping) | 100 Hz máx. |
| Tasa de muestreo | Máx. 100 kHz; ajustable o modo automático (predeterminado) |
| Resolución de columna de agua | Aprox. 7.5 mm @ muestreo de 100 kHz |
| Resolución de rango del altímetro | 1.0 mm |
| Resolución del sensor de temperatura | 0.1°C |
| Sensor de inclinación integrado | Doble eje (Roll & Pitch) ±90°, resolución de inclinación 0.1° |
| Interfaz de salida digital | RS-232, RS-485 (seleccionable) |
| Velocidad de comunicación | 4,800 ~ 921,600 baudios (115,200 predeterminado) |
| Formato de salida de datos | ASCII perfil 10/12 bit · Binario 12 bit / Companded 8 bit · Altitude NMEA0183 / Simple Altimeter · Deso-25 · Sonarmite DFX |
| Configuración y lectura de datos | EchoLogger Echosounder Control Program (Dual) o cualquier programa de terminal |
| Interconexión multi-nodo (solo RS-485) | Hasta 32 unidades |
| Conector | LTW M12A-08PMMS-SH8002 |
| Alimentación | 10 ~ 75 VDC, 2 W máx., aislado internamente |
| Temperatura de operación | -10°C a +50°C |
| Profundidad de operación | 1 m (para vehículo de superficie) |
| Carcasa | Acetal |
| Dimensiones | Ø96 mm x L90 mm (sin conector) |
| Peso | 740 g (sin cable) |
| Otras características | Uso simultáneo o independiente de ambas frecuencias · Compatible con software hidrográfico principal (Hypack, HydroMagic, HydroPro, etc.) · Datos GPS integrados |
