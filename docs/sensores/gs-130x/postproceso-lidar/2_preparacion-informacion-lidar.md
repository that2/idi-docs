## Procedimiento para Convertir .UBX / .RTCM3 a RINEX

Pasos para utilizar RTKLIB EX 2.5.0:
1. Descarga el archivo
2. Descomprimelo, puedes guardar la carpeta en cualquier ubicación en tu PC, nosotros recomendamos dejarlo en el directorio C:\
3. Puedes crear un acceso directo al archivo Convert_To_Rinex.bat y dejarlo en tu escritorio.
4. Arrastra el archivo .UBX a Convert_To_Rinex.bat
5. Se desplegará una ventana de comando mostrando el proceso de la conversión. 
6. Una vez finalizada la conversión se crearán los archivos: .OBS y .NAV del RINEX.
