# 🔬 Cuidado del sensor LiDAR

Cuidados y precauciones del sensor.

El sensor LiDAR es el componente más delicado del sistema.

:::danger[Prohibido]

- Nunca tocar el lente con los dedos.
- No exponer el sensor LiDAR al sol durante periodos prolongados.
- No utilizar alcohol industrial ni solventes.
- No almacenar el sensor con humedad.
- Nunca utilizar aire comprimido con aceite o humedad para limpiar el sensor.
- No limpiar el lente con papel, telas abrasivas o solventes.

:::

- 🧤 Mantener instalada la funda protectora cuando no esté en uso.
- 💥 Evitar con máximo cuidado golpes o caídas del sensor.

## 🧽 Limpiar únicamente con

- Paño de microfibra.
- Aire comprimido libre de aceite.
- Soluciones especiales para lentes ópticos.

## 🚁 Precaución de operación del sensor LiDAR

Durante el levantamiento se debe:

- Confirmar que el sensor haya iniciado correctamente el registro de datos antes del despegue.
- Verificar el funcionamiento del sistema GNSS/IMU.
- No cubrir el lente del LiDAR durante la operación.
- Evitar exponer el sensor al agua o polvo excesivo.
- No permitir ningún impacto del sensor, ni colocarlo en el suelo durante el despegue o aterrizaje.

## 🛡️ Protección del sensor LiDAR durante el vuelo

Para preservar la precisión del sistema:

- Evitar aterrizajes bruscos.
- No modificar la orientación del sensor durante el vuelo.
- Evitar vuelos prolongados bajo temperaturas extremas.

## 💾 Software y almacenamiento digital

Antes de guardar el equipo:

- Descargar todos los datos de vuelo.
- Respaldar la información LiDAR.
- Verificar la integridad de los archivos.
- Mantener actualizado el firmware únicamente cuando sea recomendado por el fabricante.
