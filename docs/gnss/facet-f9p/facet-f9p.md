## Archivo de configuración modo Base para Corrección LiDAR o RTK en QGC / Mission Planner
Si deseas restaurar el georeceptor al modo de por default sigue los siguientes pasos: 
1. Formatea la microSD del dispositivo en modo NTFS
2. Descarga el archivo de configuración
3. Copia el archivo a la microSD
4. Listo, tu Facet F9P se inicializará con los valores restaurados de fábrica, listo para trabajar en modo base.
